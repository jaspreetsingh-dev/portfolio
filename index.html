01 — Pulse CI

Repository analysis · Webhooks · Cloud infrastructure

View full image ↗ View full image ↗

A repository gets pushed. Pulse CI checks its dependencies, tests, documentation, and configuration, then stores a quality score in PostgreSQL. Analyses can also be started manually, without waiting for a GitHub event.

The Flask application connects GitHub webhook events and manual submissions to the same analysis workflow. Results are stored in PostgreSQL and surfaced through the dashboard.

GitHub webhook or manual submission → Flask → Repository checks → PostgreSQL → Dashboard

The application was containerized with Docker and deployed on EC2, with PostgreSQL on RDS inside a VPC. IAM, Systems Manager Parameter Store, and Secrets Manager support access and configuration; CloudWatch provides runtime logs. Terraform defines the infrastructure.

Built with

Python · Flask · Docker · PostgreSQL · AWS · Terraform

Application screenshots show manual and webhook-triggered analyses. CloudWatch logs provide a view into runtime activity.

A limitation

The check is string-based, not semantic. It searches for patterns such as password=, api_key=, and secret=, so it can flag code that handles credentials securely and miss variations such as password = "...". It detects matching strings—not whether a credential is real or exposed.

02 — GitHub Analyzer

Developer comparison · GitHub API · Scoring model

Two profiles. One comparison.

View full image ↗ View full image ↗

GitHub Analyzer compares two GitHub developers using repository statistics and language distribution, then generates a weighted Codex Score. Comparison reports are stored in Amazon S3.

The score combines five factors: Star Power (25%), Community Impact (20%), Repository Consistency (20%), Documentation Quality (20%), and Language Diversity (15%). The weighted result is normalized to a score from 0–100.

Browser → Flask on EC2 → GitHub REST API → Comparison engine → Boto3 → IAM role → S3

The application uses the GitHub REST API to gather profile and repository data. Boto3 writes comparison reports to S3 using an EC2 IAM role, avoiding hardcoded AWS credentials. Terraform defines the infrastructure.

Built with

Python · Flask · JavaScript · GitHub REST API · EC2 · S3 · IAM · Boto3 · Terraform

Application interface and comparison results demonstrate the workflow.

What the score means

The Codex Score compares observable GitHub activity and repository characteristics using a weighted model. It is not a code-quality verdict; it does not inspect whether a repository's implementation is correct, secure, or well-designed.
